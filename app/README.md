# MenuCard Android application

Flutter owner app for creating an offline digital menu and manually publishing it as a static website ZIP.

## Architecture
- The source of truth is one schema-versioned JSON file in app-private storage.
- All business logic, validation, editing, translations, backup/restore and website package generation run on-device.
- There is no backend, remote database, API server, Worker or automatic sync.
- Customer menus are static files manually uploaded by the owner.

## Run locally
The Android platform directory is generated by CI. To create it on a development machine, install Flutter stable and Android SDK, then run:

    cd app
    flutter create --platforms=android --org com.deepchandravadiya --project-name menucard .
    python tool/set_android_metadata.py
    flutter pub get
    dart format lib test
    flutter analyze
    flutter test
    flutter run

## Build a local APK

    flutter build apk --release

Unless a release keystore is configured in the generated Android project, this artifact uses the default debug signing key and is for testing only.

See RELEASE.md for signing and release requirements.
