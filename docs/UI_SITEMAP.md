# UI Sitemap

## Android owner app
1. Welcome/language: choose Gujarati, Hindi or English; explain free, local-first and no account.
2. Shop setup: required name; optional logo/contact/address; default menu locale.
3. Home: shop identity, menu counts, quick actions, “Saved on this device” state.
4. Menu management: category list and add/edit/reorder/delete; item editor for translations, INR price, availability and optional image.
5. Preview: customer-style local view with language switcher and “Local preview” indicator until publishing exists.
6. Shop profile: business details, default language and simple theme.
7. Backup/restore: export, restore preview/confirmation and backup timestamp.
8. Publish/QR (future): clear URL/publish status; enable QR only after verified public URL.

## Public one-page GitHub Pages site
- Header: MenuCard mark, Features, How it works, FAQ, Download.
- Hero: digital menu for neighbourhood businesses; strong free/offline-first promise.
- CSS-built product preview (no stock photos).
- Three-step create/preview/share section.
- Feature grid: offline management, languages, menu editing and backup.
- Honest QR note: customer needs a public URL and internet.
- Download: dynamically fetch latest APK release; show “Build in progress” if none exists.
- Footer: repository, releases and privacy note.
